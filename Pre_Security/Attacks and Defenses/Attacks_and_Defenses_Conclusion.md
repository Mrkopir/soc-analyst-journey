# Cybersecurity Fundamentals – Final Reflection

## Overview

During this learning path, I explored several core cybersecurity concepts, beginning with the **CIA Triad**, which forms the foundation of information security. The CIA model includes three main principles: **Confidentiality**, **Integrity**, and **Availability**. Confidentiality ensures that sensitive information can only be accessed by authorized individuals. Integrity ensures that data remains accurate and unaltered, while Availability guarantees that systems and data remain accessible when needed.

After understanding the security goals defined by the CIA Triad, I studied the fundamentals of **cryptography**. I learned how symmetric encryption uses a single secret key to encrypt and decrypt data, making it fast and efficient for protecting large amounts of information such as files and network traffic. I also explored asymmetric encryption, which uses a pair of keys — a public key and a private key — to enable secure communication without sharing a secret key beforehand. Modern secure protocols like HTTPS combine both approaches in a hybrid model, using asymmetric encryption to exchange a symmetric session key.

The course also introduced the **offensive security perspective**, which focuses on identifying weaknesses before malicious attackers can exploit them. I learned about concepts such as vulnerabilities, exploits, penetration testing, and red teaming. Offensive tools such as Gobuster can be used to discover hidden directories and files on a web server, while Hydra can automate password attacks by testing multiple login combinations. These tools demonstrate how attackers may attempt to gain access to systems and sensitive data.

Finally, I studied the **defensive security approach**, which focuses on protecting systems, monitoring environments, and responding to incidents. Defenders work to prevent attacks using security controls such as firewalls, patching, and antivirus tools. They also detect suspicious activity by analyzing logs and alerts, mitigate ongoing incidents by isolating affected systems, and investigate events to understand how an attack occurred and how defenses can be improved.

## Technical Understanding

Throughout this learning path, I developed a deeper understanding of how attackers discover and exploit weaknesses in systems and applications. I learned how automated tools can be used for enumeration and credential attacks, and how attackers often combine several small vulnerabilities to gain greater access.

I also gained knowledge about cryptographic mechanisms used to protect data and secure communication channels. Understanding how symmetric and asymmetric encryption work together helped clarify how secure protocols such as HTTPS protect information transmitted over the internet.

Additionally, studying both offensive and defensive approaches provided insight into how security professionals identify vulnerabilities, test system defenses, monitor infrastructure, and respond to incidents.

## Security Perspective

From a security perspective, understanding both attack techniques and defensive strategies is essential. Offensive security helps reveal weaknesses in systems before attackers can exploit them, while defensive security focuses on detecting, preventing, and responding to threats.

By understanding how attackers think and operate, defenders can better anticipate attack paths and strengthen their security controls. The CIA Triad provides the guiding principles for protecting systems and data, while cryptography ensures secure communication and data protection.

Together, these concepts form the foundation of modern cybersecurity practices and help organizations maintain secure and resilient systems.

## Conclusion

This learning path provided a comprehensive introduction to the fundamental principles of cybersecurity. Starting with the CIA Triad, I developed an understanding of the core goals of information security. I then explored cryptographic techniques used to protect data, offensive security methods used to identify weaknesses, and defensive strategies used to protect systems and respond to incidents.

These concepts create a strong foundation for continuing deeper studies in cybersecurity, including areas such as security monitoring, incident response, penetration testing, and advanced defensive security operations.
