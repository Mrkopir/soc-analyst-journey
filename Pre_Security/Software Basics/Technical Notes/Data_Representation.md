# Data Representation – TryHackMe

## 1. Data Representation
The **Data Representation** room explains how computers store and process different types of data using binary systems. It covers how numbers, characters, and other information are represented inside computer systems.

## 2. Binary System
Computers use the **binary number system**, which consists of only two digits:

- 0
- 1

Each binary digit is called a **bit**. Groups of bits form larger units such as:

- **Nibble** – 4 bits  
- **Byte** – 8 bits  
- **Word** – multiple bytes depending on architecture  

Binary is used because electronic circuits can easily represent two states (on/off).

## 3. Decimal and Binary Conversion
Computers convert numbers between **decimal (base 10)** and **binary (base 2)**.

Example:

Decimal: 13  
Binary: 1101  

Conversion is performed by dividing the decimal number by 2 and tracking the remainders.

## 4. Hexadecimal
To simplify binary representation, computers often use **hexadecimal (base 16)**.

Hexadecimal uses digits:
0–9 and A–F

Hexadecimal is commonly used for:

- memory addresses  
- machine code  
- network data
