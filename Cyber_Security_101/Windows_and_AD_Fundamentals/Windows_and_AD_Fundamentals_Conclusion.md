# Windows Fundamentals – Final Reflection (TryHackMe)

## Overview

During the *Windows Fundamentals* learning path, I gained a comprehensive understanding of the Windows operating system, its structure, and how it is used in both personal and enterprise environments. I explored how Windows has evolved over time and why it remains one of the most widely used operating systems, making it a primary target for cyberattacks.

I learned about the graphical user interface (GUI), which simplifies interaction with the system through visual elements such as the desktop, taskbar, and start menu. This interface allows users to manage files, applications, and system settings efficiently.

Additionally, I explored how Windows manages files, users, permissions, and system processes, which are essential concepts for both system administration and cybersecurity.

## Technical Understanding

Throughout this learning path, I developed a deeper understanding of the Windows file system, particularly NTFS, which supports advanced features such as file permissions, encryption, and large file sizes. I also learned how NTFS permissions control access to files and folders, allowing administrators to define different levels of access for users and groups.

I explored important system directories such as `C:\Windows` and `C:\Windows\System32`, which contain critical system files required for the operating system to function. Understanding these directories is essential for troubleshooting and security analysis.

I gained knowledge about user accounts and permissions, including the differences between administrators and standard users. I also learned how Windows manages user profiles and how tools like `lusrmgr.msc` can be used to manage users and groups.

The course introduced User Account Control (UAC), which helps protect the system by requiring confirmation before performing actions that require elevated privileges. This mechanism is important for preventing unauthorized changes.

I also explored system tools such as Task Manager, which provides insight into running processes and system performance, and System Configuration (MSConfig), which helps diagnose startup issues. Advanced tools like Event Viewer and Resource Monitor provide detailed information about system activity and performance.

## Security Perspective

From a security perspective, Windows provides multiple layers of protection to secure systems and data. Features such as UAC, NTFS permissions, and Windows Defender help prevent unauthorized access and detect malicious activity.

Understanding system tools like Event Viewer and Resource Monitor allows security professionals to monitor system behavior and investigate potential threats. The Windows Registry also plays a key role in system configuration and can be analyzed during incident response.

Regular updates through Windows Update ensure that vulnerabilities are patched, reducing the risk of exploitation. Encryption tools like BitLocker help protect sensitive data in case of device theft or loss.

Overall, these mechanisms work together to create a secure environment, but they require proper configuration and monitoring to be effective.

This learning path provided a strong foundation in understanding the Windows operating system and its core components. I developed practical knowledge of file systems, user management, system tools, and security features.

These skills are essential for cybersecurity professionals, especially in roles such as SOC analyst, where understanding system behavior, analyzing logs, and responding to incidents are critical tasks.

Overall, this course improved my ability to work with Windows systems and prepared me for more advanced topics in cybersecurity and system administration.
