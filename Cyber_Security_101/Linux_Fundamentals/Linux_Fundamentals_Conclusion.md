# Linux Fundamentals – Final Reflection (TryHackMe)

## Overview

During the *Linux Fundamentals* learning path, I gained a solid understanding of how Linux operating systems work and how they are used in real-world environments. I learned that Linux is widely used across different domains, including web servers, embedded systems, industrial infrastructure, and enterprise environments.

I explored the basic structure of Linux, understanding that it is an open-source, UNIX-based system with many distributions tailored for different use cases. This flexibility makes Linux a dominant platform in cybersecurity and server administration.

Additionally, I learned how to interact with the system using the terminal, which is a fundamental skill for both system administration and cybersecurity roles.

## Technical Understanding

Throughout this learning path, I developed practical skills in working with the Linux command line. I learned how to navigate the filesystem using commands such as `ls`, `cd`, and `pwd`, as well as how to read and display file contents using `cat`.

I also explored file manipulation commands such as `touch`, `mkdir`, `cp`, `mv`, and `rm`, which allow creating, copying, moving, and deleting files and directories. Understanding these commands is essential for managing systems efficiently.

In addition, I learned how to search for files and data using tools like `find` and `grep`, which are extremely useful for locating specific files or analyzing logs. I also became familiar with shell operators such as `&&`, `>`, and `>>`, which allow chaining commands and redirecting output.

The course introduced the concept of SSH, which enables secure remote access to systems. I also learned about flags and switches, which modify command behavior and provide more flexibility when working in the terminal.

I gained knowledge about Linux permissions, including how read, write, and execute permissions work, and how they are assigned to users, groups, and others. Understanding permissions is critical for securing systems and controlling access.

Furthermore, I explored important system directories such as `/etc`, `/var`, `/root`, and `/tmp`, which store configuration files, logs, user data, and temporary files.

In the advanced part of the course, I learned about text editors like Nano and VIM, which are used to create and modify files directly in the terminal. I also explored useful utilities such as `wget` and `scp` for downloading and transferring files securely.

Another important topic was process management. I learned how to view running processes using `ps` and `top`, and how to control them using commands like `kill`. I also understood how processes are structured and managed by the operating system, including the role of `systemd`.

Automation using `cron` was also covered, allowing scheduled execution of tasks. Additionally, I learned how package management works in Linux using tools like `apt`, which simplify installing and updating software.

Finally, I explored system logs located in `/var/log`, which are essential for monitoring system activity, troubleshooting issues, and investigating security incidents.

## Security Perspective

From a security perspective, Linux provides powerful tools and mechanisms for managing and securing systems. Understanding file permissions helps prevent unauthorized access, while tools like `grep` and system logs allow analysts to investigate suspicious activity.

The ability to monitor processes and control services using tools like `systemctl` is essential for maintaining system stability and detecting malicious behavior. Automation through cron jobs can also be used both for legitimate administrative tasks and, if misconfigured, can become a security risk.

Additionally, secure communication using SSH ensures that data transmitted over networks is encrypted and protected from interception. Understanding these concepts is crucial for working in cybersecurity, especially in roles such as SOC analyst or system administrator.

## Conclusion

This learning path provided a strong foundation in Linux fundamentals and command-line usage. I developed practical skills in navigating the filesystem, managing files and processes, working with permissions, and automating tasks.

Understanding how Linux operates at a system level, along with its tools and utilities, is essential for cybersecurity professionals. These skills are particularly important for tasks such as log analysis, incident investigation, and system hardening.

Overall, this course significantly improved my confidence in working with Linux environments and prepared me for more advanced topics in cybersecurity and system administration.
